# Monitored-service marks

These marks identify third-party services monitored by caniworknow.com. They do not imply endorsement or affiliation.

- `github.svg`, `cloudflare.svg`, and `claude.svg`: canonical brand paths distributed by [Simple Icons](https://simpleicons.org/) (CC0 package; individual marks remain subject to their owners' trademark policies).
- `openai.svg`: OpenAI Blossom extracted without modification from OpenAI's official [Design Guidelines](https://openai.com/brand/) asset.

The interface renders every mark as a monochrome CSS mask so status styling can remain accessible without altering its geometry.
